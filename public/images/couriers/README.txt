Drop your carrier logo images in this folder using these file names (SVG or PNG):

  usps.svg      (or usps.png)
  fedex.svg     (or fedex.png)
  ups.svg       (or ups.png)
  dhl.svg       (or dhl.png)
  amazon.svg    (or amazon.png)

The app references /images/couriers/<name>.svg by default and falls back to a
styled text wordmark until a file exists.
